Cómo funciona este tablero
  1. Los datos viven en postulaciones/postulaciones.json. Claude los actualiza cuando le contás novedades y genera tablero/datos.js, que es lo que lee esta página.
  2. Dejá esta pestaña abierta: se actualiza sola cada 10 segundos.
  3. Lo que marques acá (una acción hecha, una tarjeta movida, una nota) queda como cambio pendiente en este navegador. Tocá Copiar pedido para Claude, pegalo en Claude Code y Claude lo pasa al archivo. Cuando el archivo ya lo refleja, el cambio pendiente desaparece solo.
  4. El botón ⚡ de cada acción copia un pedido listo para que Claude te ayude con esa tarea.
  5. Para mover una tarjeta, arrastrala a otra columna o abrí su detalle y elegí la columna.

No pude copiar automáticamente. Seleccioná el texto y copialo con Ctrl+C (Cmd+C en Mac):
